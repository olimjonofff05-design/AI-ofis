# AI Ofis

8 ta AI agentdan iborat ishchi jamoa va ularning ishini jonli ko'rsatadigan "ofis" ekrani.

| Agent | Vazifasi |
|---|---|
| Rais | Vazifani qabul qilib, mos agentga topshiradi |
| Hujjatchi | Prezentatsiya, Word, Excel, PDF, matnlar |
| Tadqiqotchi | Internetdan qidiruv va tahlil |
| Rassom | Rasm generatsiyasi va tahriri |
| Montajchi | Video montaj, namuna uslubida video yig'ish |
| Jarvis | Kompyuterni ovoz va matn bilan boshqarish |
| Qo'riqchi | GitHub repolar xavfsizligi |
| Tekshiruvchi | Natijalar sifatini tekshirish |

## Hozirgi holat
- `office-ui/index.html`: jonli ofis, vazifa berish, loyihalar sahifasi va xodimlar ro'yxati (brauzerda oching).
- Agentlar hali ulanmagan: bu 1-bosqich ishi.

## Bosqichlar
1. MVP: Rais, Hujjatchi, Tekshiruvchi, ofis sayti, Telegram (2–3 hafta)
2. Qo'riqchi, Tadqiqotchi, ruxsat so'rovlari (2 hafta)
3. Jarvis: Windows boshqaruvi, ovoz (3 hafta)
4. Rassom, Montajchi, uslub pasporti (3–4 hafta)
